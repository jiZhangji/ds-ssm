## 五、必须逐项回答的研究问题

### A. Matched Base

检查 Original 与 RGSP 之间的扫描、通道扩展、局部算子、FFN、归一化、投影、残差和初始化差异。

明确：

- Original 保留用于整块系统比较。
- Matched Base 用于新增机制归因。
- 同参数量不等于同结构。
- 同 seed 不一定保证共同层初值一致。

特别核查中性控制：

$$
\gamma=0.5+0.5\sigma(0)=0.75.
$$

将 alpha=0、关闭 PFIM 不等于 gamma=1；固定 I=0.5 但保留 eta I 也不等于关闭 Delta 条件化。

请给出明确的中性定义，说明是否需要固定缩放控制，以及哪些现有实验因此不能直接复用。

### B. Input／Delta 四格

优先固定局部修正与能量背景，设计：

- M00：I 不作用于 input，也不作用于 Delta。
- M10：I 只作用于 input。
- M01：I 只作用于 Delta。
- M11：两者都启用。

关闭 I → input 必须同时关闭 I 对 gamma 和 write gate 的影响；是否保留能量项要写清楚。

报告应分析：

$$
M_{10}-M_{00},\quad
M_{01}-M_{00},\quad
M_{11}-M_{10},\quad
M_{11}-M_{01}.
$$

以及结构匹配下的交互对比：

$$
J=M_{11}-M_{10}-M_{01}+M_{00}.
$$

不要只看 Delta-only 是否提高；还要看 Delta 加在 Input-conditioned 上的条件贡献。不要把 AP 交互对比直接当成内部机制证明。

### C. LRC 与能量

现有 LRC-only 同时包含残差修正和能量调制。检查是否需要拆分，或者至少调整名称。

核对：

$$
\tilde{x}=x-\lambda(x-K*x)
=[(1-\lambda)\delta+\lambda K]*x.
$$

这一等价关系仅针对当前线性残差修正分支，不是把整个 RGSP 简化为卷积。

讨论固定滤波、相同初始有效核的可学习逐通道卷积与当前参数化之间的必要对照。不要把特征域修正未经验证地称为 SAR 去斑。

### D. 主表与消融的连接

当前稿件历史 RGSP AP50:95 72.261%，三种子 Full 42.91%；历史 Original 约 70.348%，当前约 42.03%。

不能直接比较两轨增益，也不能凭差距断言当前实现有 bug。

逐项核查训练图数、epochs、初始化、结构、state_dim、增强、优化器、调度、选模和评估。

当前代码 fitness 为 0.1 AP50 + 0.9 AP50:95；旧协议中的单指标选模表述需绑定历史版本。完整 runner 的 --cos-lr 是显式选项，不能只信文档“默认 cosine”。

给出 result → checkpoint → config → code → split → selection 的证据链及缺口。

### E. Reliability 与空间粒度

I 是由局部趋势和标准差生成、通过任务损失学习的信号，不自动是概率或校准可靠性。

检查 beta、rho、eta 的约束及符号。A<0 时 Delta 增大增强历史状态衰减，并改变输入项；不能笼统说 Delta 大等于长记忆。

按必要性排序：

- I 及实际 gamma × write gate 的统计。
- 结构引起的 Delta 变化。
- 强度匹配的目标／背景结构比较。
- 正常、空间打乱、Global、常数引导。
- 合理扰动下的性能与稳定性。
- 小规模状态传播探针。

区分训练后干预与重训消融。未标注亮点不是天然的无用杂波；检测框不是精确掩码；像素数量不是独立样本数。

说明保留 Reliability 需要什么证据，不补时如何收紧为结构条件化。

### G. 竞争性、效率与完整性

建议少量可靠的同协议代表性外部对照，不堆不可比文献表。

区分严格模块归因与合理训练的跨架构竞争比较，不以一套不适合所有模型的超参数制造公平假象。

核查：

- THOP 是否覆盖自定义 scan，非零 FLOPs 也可能漏计。
- batch 每图时间、batch=1 延迟、吞吐与端到端 FPS。
- 整块轻量化与引导模块本身开销。
- Recall 的最优 F1 阈值口径，是否应补 PR 或固定误警比较。
- 定性图是否包含改善和退化。
- 数据集设置、结果、引用和补充材料是否一致。
- 当前双栏预览与完整论文源文件的对应关系。

## 六、输出格式

请按下列结构提供最终结果。

### 1. 总体判断

### 2. 证据清单

逐项列出已读文件、版本、数值复算、未访问资料及不确定性。没有访问的服务器或原论文不要声称已核验。

### 3. 严重性排序

每项给出：

- 是否真实存在。
- 严重程度与原因。
- 必须补实验还是可以收紧 claim。
- 最小可接受证据。
- 对应论文章节。

### 4. 最小实验矩阵

每行至少包含：

- 建议 Experiment ID。
- 科学问题。
- 对照背景。
- 残差、能量、I → gamma、I → write、I → Delta 的开关。
- 固定缩放和常数偏置约定。
- 扫描、state_dim、FFN、归一化和初始化。
- 数据集、划分、种子、训练预算。
- 选模指标、主要评价指标。
- 现有结果可复用／需重跑／证据不足。
- 结果不同方向对应的论文决策。

不要把未知参数凭空填成已冻结事实。

### 5. 分阶段计划与数量

依次为证据审计、核心三配置、按结果选择机制诊断、第二数据集确认、竞争性与效率。

明确“3 个配置 × 3 种子 = 9 次新训练”只在旧结果可复用、无需额外控制时成立。不要在未检查资源和耗时记录时编造 GPU 小时或完成时间。

给出停止扩展、转向诊断的条件，避免一开始铺满所有数据集和所有因素全排列。

### 6. 主张与章节修订

覆盖标题、摘要、引言、相关工作、方法、实验、讨论、结论和补充材料。提供可直接使用的审慎措辞。

### 7. 最终方法决策

分别分析 Full 有效、简化版更好、特定能力占优和设计研究四种路线。不要预设 Full 必须最高，也不要把负结果重新命名为设计研究就视为成功。

### 8. 投稿准备度

依据证据完整性给判断，不编造接收概率，不承诺补完固定数量实验一定能被顶会或期刊接收。
