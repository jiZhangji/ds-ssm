## 2. 题目和术语

保留用户的可靠性引导方向和英文题目，RGSP 是本轮论文工作名称。“可靠性”是希望解释的任务相关属性，PFIM 实际输出是任务驱动的空间重要性/控制量；二者不能未经验证画等号。

## 3. 对照代码修正的方法

- 趋势是展平序列上的可学习1D depthwise k=3卷积，不是固定二维平滑；行边界成为序列邻居。
- 当前块局部修正标量初始值为0.5，无凸组合约束，不能保证始终平滑或去噪。
- PFIM 输入为趋势与修正特征的二维标准差，输出每位置一个标量；末层零初始化使 I=0.5，但整个模块不是恒等初始化。
- gamma 与 write factor 共同乘在同一输入驱动位置；delta 同时影响历史衰减与当前写入，不是独立保留门。
- B/C 来自未乘 q 的内容投影；D 旁路使用修正特征，SiLU 输出门在扫描核外。
- Global 先逐位置预测再平均，只消除 I 的位置差异；关闭二维统计的旧开关实际改用一维统计。
- Tiny 深度缩放后 P3/8 实际执行一个替换块，不是名义配置中的三个。
- 原块到替换块同时改变扫描、归一化和前馈结构，主表解释整块替换；同结构机制对照待完成。
- 跨任务骨干内部替换、legacy stride16、VMamba输出适配器分开报告。

## 4. 实验数字与结论

SSDD来自原包15个run，以原始精度复算，CSV未改。AP50:95为：

| 变体 | 均值 ± 样本标准差（%） | 相对基线平均差（pp） |
|---|---:|---:|
| Baseline | 42.03 ± 3.47 | - |
| DS-only | 43.98 ± 1.44 | +1.95 |
| PFIM-only | 43.12 ± 1.70 | +1.09 |
| Full / RGSP | 42.91 ± 1.13 | +0.88 |
| Global | 43.77 ± 1.65 | +1.74 |
