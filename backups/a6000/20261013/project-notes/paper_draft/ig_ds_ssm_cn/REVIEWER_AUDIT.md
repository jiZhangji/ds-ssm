# 审稿视角检查：IG-DS-SSM / PFIM

本检查依照用户提供的 reviewer prompt 中的 Summary、Strengths、Critical Weaknesses、Overall Rating 和 Strategic Advice 结构撰写，重点核对贡献边界、实验严谨性、消融完整度和主张是否受证据支持。参考提示词：[awesome-ai-research-writing](https://github.com/Leey21/awesome-ai-research-writing#论文整体以-reviewer-视角进行审视)。以下是内部模拟审稿，不代表任何期刊或会议的正式评审。

## Summary

稿件提出面向 SAR 视觉状态空间模型的局部残差修正和空间重要性调制，并在 SSDD 上完成五变体、三种子的内部消融。当前结果显示 DS-only、PFIM-only 的 AP$_{50:95}$ 描述性均值高于 baseline，但朴素组合低于 DS-only，token-wise 未优于 image-wise。分类、变化检测和分割记录方向不一，且大多为单种子诊断。稿件在结论边界上较为克制，但检测主验证集、结构匹配消融和外部基线仍不足以支撑广泛的 SAR 方法结论。

## Strengths

- SSDD 结果包含 15 个 run、逐 seed 配对结果和权重哈希；报告均值、标准差及负向 seed。
- 论文明确区分“设计假设”和“已证实机制”，没有把局部统计直接称为物理散斑估计或目标解释图。
- 组合负交互、image-wise 对照以及跨任务负结果均保留，摘要与结论没有宣称全任务提升。
- 方法实现说明披露 baseline 与改造块之间存在 MLP ratio、归一化及扫描结构差异。

## Critical Weaknesses

- 关键跨数据集三种子验证和同预算轻量外部检测器复现尚未完成，无法判断结果能否迁移或相对现有检测器的竞争力。
- baseline 与 DS-SSM 的 block 配置不完全匹配，SSDD 结果不能隔离局部残差公式的因果作用。
- 三个 seed 同时改变训练/验证划分，且样本量很小；数据集间的单种子记录不能建立统计性泛化结论。
- gamma、write 和 delta 调制路径缺少逐项机制消融；已有 PFIM 热图来自协议不匹配的历史检查点。
- 速度计时缺硬件和复测元数据；分割 manifest 与数据场景隔离审计尚未完整归档。
- Related Work 已补入 MaDiNet、MCMN、RSS-Net、MambaDIP、SAR-NanoShipNet 和 SFD-Net 等近年 SAR 状态空间、去斑及检测工作，并修订若干作者与出版信息；该综述仍是代表性抽样，不是穷尽检索，投稿前仍应按目标期刊范围继续扩展并逐条核对全部引文。

## Overall Rating

**4/10（内部模拟：当前版本不建议直接投稿）**。这个分数评价的是证据完整度和投稿准备度，不是对研究方向价值的判定。当前更接近有可审计核心消融与负结果的完整工作稿；若目标期刊要求多数据集和外部方法对比，现阶段主要实验仍不足。

## Strategic Advice

1. 优先完成 SAR-ShipDataset、SAR-AIRcraft1.0 的相同划分、scratch、相同预算四变体三种子矩阵，并至少重实现一个轻量检测基线。
2. 将 baseline 与改造块的归一化、MLP 宽度及残差路径对齐，再单独评估局部残差、PFIM 和各状态调制支路。
3. 保持当前克制主张：将跨任务数字作为适用范围诊断；在单场景和单种子结果之外，不作普遍泛化结论。
4. 统一重测参数量、GFLOPs、延迟/FPS，归档设备、精度、输入尺寸、batch、预热和计时重复次数。
5. 投稿前绑定代码 commit、split manifest 哈希、每个 run 的配置/日志/权重哈希，并完成数据场景泄漏检查。

本检查是内部审稿清单，不替代目标期刊格式检查，也不把未完成实验升级为事实。

## 当前稿件可支持的主张

1. 在 SSDD 当前从头训练、五变体、三个 seed 的实验矩阵中，DS-only 与 PFIM-only 的 AP50:95 均值分别比基线高 1.95 和 1.09 个百分点。
2. 三个 seed 的配对变化存在正负波动，n=3 仅支持描述性报告。
3. full 比 DS-only 低 1.07 个百分点，且三个 seed 中有两个低于基线；不能声称两模块稳定互补。
4. global/image-wise 记录高于 token-wise full，当前结果不支持更细粒度重要性图更有效。
5. 历史分类、变化检测和分割记录方向不一；它们只能用于说明待验证范围和潜在边界。

## P0：投稿前必须解决

- 完成 SAR-ShipDataset、SAR-AIRcraft1.0 上的同协议三种子验证，保留 baseline、DS-only、PFIM-only、full，固定 split、初始化、输入和训练预算。
- 至少补一个同划分、同 scratch/预训练政策、同预算的轻量检测器复现。论文目前没有足以支撑“超过主流方法”的证据。
- 将 baseline 与 DS-only 的 block 改动拆开控制。当前归一化、MLP ratio 和扫描结构也发生变化，无法把整项差异归因于局部残差修正。
- 对 SSDD 数据 manifest、场景级重复和 test 使用范围完成可审计检查；本文目前没有独立的数据泄露审计结论。
- 将公式中的所有符号、张量维度、插入 stage/stride、扫描方向、边界处理和初始化逐项绑定到将投稿的源码 commit。

## P1：显著增强可信度

- 在相同设备、精度、batch=1 和 profiler 下重新测完整检测器参数量、GFLOPs、延迟/FPS，保存设备型号、预热、同步和重复次数。
- 增加以其余 block 结构不变为前提的局部残差、PFIM、gamma/write、delta 路径消融。
- 增加 baseline 与固定 Lee 去斑预处理的同协议对照，以区分可学习状态更新与固定滤波的贡献。
- 用预先固定的验证方案报告小/中/大目标或背景复杂度分层结果；避免基于 test 结果挑选分组界线。
- 对分类、变化检测和分割选定统一任务接口及多 seed 协议；如果没有资源复验，保持为探索性附录并保留负结果。
- 为 PFIM 可视化补充跨 seed 稳定性、目标/背景统计和重要性扰动分析，不能把热图直接命名为目标掩膜或因果解释。

## P2：表达和材料完整性

- Related Work 逐篇对照正式出版页面核验题名、作者、年份和卷期；补充 SAR-Mamba 与检测方法的机制对照表。
- 为所有检测和分割结果关联实验 ID、配置、评估脚本、checkpoint 哈希、split manifest 和日志位置。
- 论文主表只列可比的同协议实验；reported literature、历史重跑和 partial evidence 分开展示。
- 补失败案例图及定量误检/漏检统计；样例选择规则在查看 test 结果前确定或明确标为定性示例。
- 按目标期刊重新排版，并补齐作者、通讯信息、致谢、基金、数据/代码可用性声明。

## 审稿结论模拟

当前稿件更适合作为有完整内部结果账本的研究稿，而非已达到投稿条件的完整方法论文。最容易被拒稿的原因不是 SSDD 均值为负，而是跨数据集及外部基线证据不足、关键模块消融被 block 结构差异混杂、机制解释强于直接证据。若上述 P0 工作未完成，摘要和结论应继续采用当前克制表述，并将文章定位为初步受控研究。
