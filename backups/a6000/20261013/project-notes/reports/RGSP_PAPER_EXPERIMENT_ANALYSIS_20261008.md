> 现有结果支持继续研究局部修正与结构条件化，但尚未充分证明完整 RGSP 的核心归因、稳定优势和可靠性解释。

## 3. 把论文的主张分成不同证据层级

论文包含三个强度不同的主张：

1. 替换为 RGSP 后，任务性能改善。
2. 改善主要来自局部响应修正和结构条件化，而不是其他结构变化。
3. 结构引导识别了更值得传播的信息，并通过改变写入与状态演化改善 SAR 表征。

三者不能由同一张性能表全部证明。

| 要回答的问题 | 所需证据 |
|---|---|
| 整块替换是否有效 | Original 与最终模型的同协议比较 |
| 新增机制是否有效 | 同结构 Matched Base |
| 各组件有什么作用 | 单因素或严格定义的因素消融 |
| 显式局部结构是否必要 | 普通内容门控、局部描述与全局引导对照 |
| Delta 条件化是否有贡献 | 输入／步长路径的四格比较 |
| 是否具有可靠性语义 | 信号、实际控制量、区域或扰动诊断 |
| 是否能跨数据条件成立 | 第二数据集的关键确认性实验 |
| 是否有实际竞争力 | 代表性同协议基线和规范效率测量 |

现有证据主要覆盖第一层的一部分和第二层的初步探索。第三层明显不足。

## 4. 现有 SSDD 结果的准确解读

### 4.1 多种子汇总

AP 以百分数表示，差值以百分点（pp）表示，标准差为样本标准差。

| 配置 | AP50:95，均值 ± 标准差 | 相对 Original 的平均变化 | Seed 0 / 1 / 2 配对变化 |
|---|---:|---:|---|
| Original VSSBlock | 42.03 ± 3.47 | — | — |
| 现有 LRC-only / ds_only_p3 | 43.98 ± 1.44 | +1.95 | +2.90 / +5.26 / −2.30 |
| LSGM-only / pfim_only_p3 | 43.12 ± 1.70 | +1.09 | +2.13 / +3.16 / −2.00 |
| Full / full_p3 | 42.91 ± 1.13 | +0.88 | −0.35 / +5.93 / −2.94 |
| Global / global_p3 | 43.77 ± 1.65 | +1.74 | +2.29 / +6.15 / −3.23 |

配对增益标准差：

- LRC-only：约 3.87 pp。
- LSGM-only：约 2.73 pp。
- Full：约 4.57 pp。
- Global：约 4.71 pp。

### 4.2 不能把较小的 AP 方差等同于稳定增益

Full 自身 AP 的标准差为 1.13，但相对 Original 的配对差标准差为 4.57，且三个种子中两个为负。

因此应区分：

- 模型自身性能的跨种子波动；
- 相对对照的增益波动。

现有数据支持“正向平均差”，不支持“稳定优于基线”或统计显著性结论。不要用 2/3 同号作为已经证明稳定性的标准。

### 4.3 不应把 seed 2 的 baseline 认定为 outlier

三个 Original AP50:95 为 42.69、38.27、45.12。最高值不自动是异常值。

所有变体在 seed 2 下低于 Original，可能涉及数据划分、结构适配、优化或选模差异。不能未经验证就归因于“baseline 幸运”。

应保留该种子，报告全部结果，并将原因写为尚未分离。旧报告中“outlier”“已确认 split 方差”的解释不应继续当作已证实事实。

### 4.4 Full 低于 LRC-only：条件收益不足，不等于机制负交互已被证明

Full − LRC-only 的逐种子差值约为：

- Seed 0：−3.25 pp。
- Seed 1：+0.68 pp。
- Seed 2：−0.64 pp。
- 平均：−1.07 pp。

准确结论：

> 在当前局部修正与能量调制配置之上加入 LSGM，没有体现正向平均收益。

不能直接升级为：

> 两模块必然冲突，或 PFIM 在状态空间内部造成了已证实的负交互。

### 4.5 Global 与 Token-wise

Global − Full 的逐种子差值约为 +2.64、+0.21、−0.29 pp，平均 +0.86 pp。

可以说当前设置未体现 Token-wise 在 AP50:95 上的优势，但不能据此确定：

- Global 在所有任务上更好；
- Token-wise 设计失败；
- 原因一定是过拟合；
- 有效性仅来自全局调节。

Global 是对逐位置预测的 I 在空间上取均值后再广播；内容、趋势能量和基础步长仍可随位置变化，不是整个 SSM 变为非选择性模型。

## 6. 必须补的第一组：结构匹配基线

### 6.1 保留两个职责不同的基线

Original Baseline 回答实际系统层面的整块替换效果。

Matched Base 回答在相同块结构下，新增机制是否有贡献。

二者不能互相替代。Original → Full 存在扫描、内部扩展、投影、局部结构、前馈和残差等变化；仅对齐参数量仍不足以建立机制归因。

### 6.2 Matched Base 应保持一致的内容

- P3/8 插入位置及实际执行块数。
- 通道数与特征尺寸。
- 单向行优先扫描顺序。
- 状态维数及内部扩展方式。
- 输入、输出投影和旁路。
- FFN 比例、激活、Dropout。
- 归一化和块级残差缩放。
- SSM 参数初始化。
- 数据划分、预处理、训练预算、优化器与选模。

同一 seed 不保证共同层初始化完全一致：模块创建顺序可能消耗不同的随机数。必要时固定共同参数初始化，并公开如何处理不共有参数。

### 6.3 重要陷阱：关闭开关不自动等于恒等控制

当前：

$$
\gamma_t=g_{\min}+(1-g_{\min})\sigma(\cdots),\qquad g_{\min}=0.5.
$$

若能量项和结构项都置零：

$$
\gamma_t=0.5+0.5\sigma(0)=0.75.
$$

因此将 alpha 置零、关闭 PFIM，仍保留 0.75 的扫描输入缩放。

同样，若固定 I=0.5 但保留 Delta 条件项：

$$
\Delta_t=\operatorname{softplus}(W_\Delta u_t+b_\Delta+\eta I_t),
$$

初始 eta=0.1 时仍有 0.05 的 logits 偏移。

必须区分：

1. 输入缩放完全旁路，gamma=1、write gate=1。
2. 保留固定缩放 0.75，关闭动态调节。
3. 完全关闭 Delta 的结构附加项。
4. 保留常数 Delta 附加项。

建议首先定义真正的机制关闭版本；若希望复用现有实验，再用固定缩放控制连接现有语义。不能把以上四种状态混称为“neutral”。

### 6.4 关闭组件时仍有支撑计算的问题

即使关闭残差修正，局部趋势仍可能被 LSGM 或能量分支使用。因此：

- lambda=0 不等于所有趋势计算都不存在。
- 关闭 LSGM 不等于能量调制不存在。
- 关闭 I 对输入的影响不等于所有输入缩放都不存在。

实验表应写明“该项是否影响输出”，不要只靠模块名或参数是否存在判断。

## 7. 必须补的第二组：Input／Delta 四格

### 7.1 最小、可解释的路径矩阵

优先固定现有局部修正与能量调制背景，只改变 I 的两个作用路径。

| 配置 | 局部修正与能量背景 | I → 扫描输入 | I → Delta |
|---|---|---:|---:|
| M00 | 固定 | 关闭 | 关闭 |
| M10：Input-conditioned | 固定 | 开启 | 关闭 |
| M01：Delta-conditioned | 固定 | 关闭 | 开启 |
| M11：Both / Full | 固定 | 开启 | 开启 |

M00 在语义上接近现有 DS-only，M11 对应 Full。能否直接复用必须按冻结版本核查。

这里的 Input-conditioned 和 Delta-conditioned 指结构条件路径，不表示整个模型完全没有其他输入处理或内容相关步长。

### 7.2 输入路径有两个受 I 影响的因子

$$
u_{\mathrm{scan},t}=\gamma_t g_{w,t}u_t.
$$

关闭 I → input 时应同时关闭 I 对 gamma 和 write gate 的影响。若固定背景包含能量调制，则能量项应保持不变。

现有代码中有相关开关与类，不代表对应严格实验已经完成；还需检查入口适配、实际 state_dim、共同初始化与冻结参数。

### 7.3 重点看条件贡献

Delta 在无输入条件化时的贡献：

$$
M_{01}-M_{00}.
$$

Delta 在已有输入条件化时的贡献：

$$
M_{11}-M_{10}.
$$

后者尤其关系到 Full 的必要性。

Delta-only 无增益，不等于 Delta 必然无用；如果其在 Input-conditioned 上有稳定条件贡献，仍可能有互补价值。反过来，单独有效也不保证组合有效。

### 7.4 交互对比

在结构与其他因素一致的四格设计中，逐种子计算：

$$
J_s=M_{11,s}-M_{10,s}-M_{01,s}+M_{00,s}.
$$

报告均值、波动与方向，不凭 Full − DS-only 代替交互对比。交互依赖指标尺度，负的 AP 交互对比也不直接证明内部物理或表征机制。

### 7.5 结果与论文定位

| 观察 | 论文处理 |
|---|---|
| Input 与 Delta 的条件贡献均可信 | 保留双路径贡献 |
| Input 有效、Delta 没有额外收益 | 降低 Delta 地位，考虑简化 |
| Delta 有效、Input 无贡献或干扰 | 考虑 Delta 为主的结构 |
| 两者都不优于同结构控制 | LSGM 的有效性未建立 |
| 仅整块替换有效 | 不把主要收益归因于局部可靠性机制 |

## 8. LRC 与能量调制需要分开理解

### 8.1 现有 LRC-only 不是纯 LRC

当前实验标签同时包含趋势残差修正和趋势能量相关输入缩放。因此 +1.95 pp 不能单独归因于残差修正。

若 LRC 是独立贡献，建议比较：

| 配置 | 残差修正 | 动态能量调制 |
|---|---:|---:|
| 同结构控制 | 关闭 | 关闭 |
| Residual correction | 开启 | 关闭 |
| Energy modulation | 关闭 | 开启 |
| 当前 LRC-only 组合 | 开启 | 开启 |

各行的固定缩放约定必须一致或单独控制。不必立即与所有其他因素做全排列。

若不补，应将现有实验标签解释为 Local correction + energy modulation，避免误称纯单组件。

### 8.2 残差修正分支可等价为局部线性滤波

当前定义：

$$
\bar{x}=K*x,\qquad
\tilde{x}=x-\lambda_s(x-\bar{x}).
$$

因此：

$$
\tilde{x}=(1-\lambda_s)x+\lambda_s(K*x)
=K_{\mathrm{eff}}*x,
$$

$$
K_{\mathrm{eff}}=(1-\lambda_s)\delta+\lambda_s K.
$$

在当前线性逐通道卷积、块级标量及对应填充定义下，残差修正分支可以写成一个有效逐通道卷积核。

这不等于整个 RGSP 是一个普通卷积：趋势还用于能量和结构分支，后续含动态条件化与递推。这里仅限制对 LRC 分支本身的新颖性解释。

其可能价值包括初始化、优化参数化与共享趋势描述，但需要通过对照证明，而不是单凭形式命名。

### 8.3 有价值的普通滤波对照

- 固定局部滤波。
- 普通可学习逐通道卷积。
- 当前 LRC 参数化。

可令普通卷积与 LRC 初始有效核一致，减少初始化混杂。函数表达等价不表示参数化后的优化和正则化轨迹相同。

### 8.4 不默认称作去斑

lambda 与卷积权重可学习，未见强制保持低通性质的约束；训练后可能平滑、保留或增强局部变化。

操作发生在特征域，趋势能量与局部标准差不能直接当作原始 SAR 强度的散斑统计。“局部响应修正”比未经证明的“去斑”更准确。

## 9. 历史主结果与当前消融之间的连接性问题

### 9.1 当前稿件中的两个性能水平

- 历史主表 RGSP AP50:95：72.261%。
- 三种子 Full 消融均值：42.91%。
- 历史 Mamba-YOLO-T：约 70.348%。
- 当前 Original 三种子：约 42.03%。

它们不是同条件结果，不能直接计算模块增益。脚注说明协议不同是必要的，但仍不足以连接高分性能与机制证据。

审稿人可能追问：

> 用于展示性能的模型，与用于验证机制的模型，是否是同一明确版本，并处于可信的训练工作状态？

### 9.2 需要逐项核查

- 742 与 928 张训练图像。
- 150 与 300 epoch。
- 学习率、调度、batch、增强。
- clean scratch 与部分迁移。
- 旧拓扑与当前 P3 拓扑。
- 实际状态维数及入口参数解释。
- 验证集与测试集角色。
- best checkpoint 选择依据。
- 评估分辨率、NMS、IoU 与指标实现。

历史报告只能提示候选差异，不能替代 72.261% 这一条结果的完整来源链。

每个重要结果需绑定：

> result → checkpoint → run config → code version → data split → selection rule。

### 9.3 两个具体协议记录风险

当前 metrics.py 的 fitness 为：

$$
0.1\,AP_{50}+0.9\,AP_{50:95}.
$$

旧协议中“仅按 AP50:95 选 best”的描述需绑定历史运行版本后校准。所有模型使用相同规则仍可公平比较，但文字必须准确。

旧协议将 cosine 调度称为默认；当前完整 runner 的 --cos-lr 是显式启用项。不能由此断言历史运行有误，应查看实际参数和学习率记录。

### 9.4 建议的两轨处理

先在已有 150 epoch 轨道完成核心机制归因；再对 Original、Matched Base、关键简化配置和最终方法做统一的充分训练验证。

充分训练由验证曲线、收敛表现和统一预算判断，不预设 300 epoch 一定正确。改变预算时对关键整组统一改变，旧轨道单独报告。

不要只给 ours 延长训练，也不要用历史目标数据集 checkpoint 微调后冒充外部预训练。

## 10. Reliability 命名与机制证据

### 10.1 两条可行路线

路线 A：将主张收紧为结构条件化。

当前实现明确支持“从局部趋势和邻域变化生成条件信号，并用于输入和步长”；尚不直接支持“准确估计局部可靠性”。

可考虑 Structure-Guided 或 Structure-Conditioned 的表述，但改名不替代有效性验证。

路线 B：保留 Reliability，并给出可检验定义与证据。

例如把可靠性操作化为扰动稳定性及任务相关结构贡献，而不是把任何高值热图直接叫可靠区域。

### 10.2 高 I 不自动代表更强保留或写入

beta、rho、eta 为可学习系数，不能预设训练后符号与语义。

同时：

$$
A=-\exp(A_{\log})<0.
$$

增加 Delta 会增强对应历史状态分量的衰减，同时改变当前输入项。因此：

- I 高不必然更可靠。
- I 高不必然写入更强。
- Delta 大不等于记忆更长。

应检查实际组合控制量，不只展示 I。

### 10.3 推荐的机制记录

- I 的分布、空间变化及饱和情况。
- 总输入缩放 gamma × write gate。
- 结构条件项引起的 Delta 变化。
- 需要时记录 exp(Delta A) 的统计。
- 各可学习标量的符号、幅值和训练轨迹。

原始跨模型特征、Delta 或热图可能有尺度差异；直接比较颜色或绝对量前要说明聚合与归一化方式。

### 10.4 强度匹配的区域比较

比较目标内部、边缘、弱散射目标、疑似孤立强散射和普通背景，重点是相近响应强度但邻域结构不同的区域。

注意：

- 检测框不是像素级精确掩码。
- 未标注亮点不自动是无用杂波。
- 背景上下文可能有效。
- 区域定义和人工核查应公开。
- 不把单图中的大量像素当作大量独立样本；统计应考虑图像或场景层级。

### 10.5 引导信号干预

候选对照：

1. 正常空间引导。
2. 同图像内空间打乱引导，保留值分布但破坏对应关系。
3. 图像均值引导。
4. 固定常数引导。

训练后干预研究模型依赖，重训控制版本研究设计优劣。临时关闭导致下降可能包含分布偏移，不能替代重训消融。

### 10.6 扰动鲁棒性

如采用人工乘性扰动，必须明确输入是强度、幅度还是显示映射后的图像；不同输入域的扰动定义不一样。

在真实 SAR 图上追加噪声属于附加干扰评估，不等于拥有干净参考的去斑实验。报告原始性能、预设扰动等级及性能下降，并保留真实困难场景分析。

### 10.7 状态传播探针

可在匹配块局部位置施加小扰动，观察不同扫描距离的输出变化。需控制扰动幅度、扫描方向，以及是否固定动态系数和引导信号。

这是机制诊断，不是 SAR 噪声的完整物理验证；应在性能归因建立后作为补强。

## 11. 数据集选择

| 数据集 | 建议角色 | 优先实验 |
|---|---|---|
| SSDD | 核心机制消融 | Matched、路径四格、必要的 LRC／能量拆分、机制图 |
| SAR-ShipDataset | 第二数据集确认 | Original、Matched、最终配置、关键简化对照 |
| SAR-AIRcraft1.0 | 扩大目标类别范围的候选 | 在严格切片与原图评估协议下验证关键配置 |
| SAR-ACD | 公平跨任务验证候选 | 区分模块与预热策略 |
| Ottawa / Yellow River | 变化检测适用边界 | 统一配置，保留正负结果并分析区域差异 |
| OpenEarthMap-SAR / FUSAR-Map | 密集预测边界 | 类别、边界、细结构与插入尺度分析 |

### 11.1 SSDD 优先的理由

已有 15 次实验、配对划分和较完整记录，可以接续验证。优先不是因为它可能更容易获得正结果。

SSDD 规模较小，不适合独自支撑通用 SAR 结论。

### 11.2 第二数据集不需要全量复制矩阵

根据 SSDD 的结果选择最能验证核心结论的对照。若主打 Delta，保留去 Delta 对照；若主打 LRC，保留普通滤波或无修正对照。

两个舰船数据集能够支持跨数据集验证，不自动支持跨目标类别或跨任务普适性。

### 11.3 SAR-AIRcraft1.0 与 AIR-SARShip-2.0 不可混用

它们是不同数据集。需明确原图划分、切片、重叠、空背景、预测合并以及 patch／原图级指标。原则上先按原图或场景划分，再切片，避免关联切片跨集合。

当前稿件实验设置与结果小节的数据集范围不一致，应统一。

## 12. 跨任务结果的重组

### 12.1 SAR-ACD

当前稿件 baseline 89.764%，RGSP 96.850%，但 RGSP 含额外模块预热日程。

目前只能解释为模块与训练策略的组合结果。建议核对：

- baseline 原策略。
- baseline 匹配预算或对应分阶段策略。
- RGSP 无额外预热。
- RGSP 有额外预热。

需核查预热究竟冻结哪些参数、是否增加更新次数；不能机械地以“都多训练 50 轮”认为完全匹配。

### 12.2 SAMPLE

本项目 real-only／闭集设置不同于文献 synthetic-to-measured。不同任务定义的结果分组后仍不构成同协议竞争性比较。

正文优先同协议 baseline 与 ours；不同任务的文献数值可作为背景，不应占据主证据位置。

### 12.3 Ottawa 与 Yellow River

Ottawa 部分重跑设置正向，Yellow River 多个设置负向，适合作为适用边界。

候选分析包括变化区域面积、低对比度区域、边界与内部、Precision／Recall 和对应控制量。

不能未经诊断断言“弱变化被抑制”。当前稿件“Yellow River 各重跑配置 Precision 均提高”有误，BS32、BS64 实际下降，应修正。

### 12.4 分割

OpenEarthMap-SAR 未显示跨配置一致增益。历史 FUSAR-Map 的道路退化记录应绑定原始结果后再进一步分析。

重点看每类 IoU、细长结构、边界、小区域和插入尺度，而不只看整体 mIoU 接近。

### 12.5 推荐总述

> 我们在多个 SAR 任务上评估该机制的适用性与局限。结果显示其收益依赖任务、数据和训练配置，部分密集预测设置出现退化。

接口能接入多个任务，不等于多个任务性能稳定提高。保留负结果不代表必须让每个任务都提升，但也不自动构成有价值的边界研究；仍需总结可检验条件。

## 13. 同协议外部对比、效率与定性实验

### 13.1 外部基线

少量可信的同协议比较比大量不可比文献行更有说服力。优先考虑：

- 原始 Mamba-YOLO。
- 代表性轻量 CNN 检测器。
- 可可靠复现、任务相关的 SAR 或视觉 SSM 方法。

机制对照可增加普通内容门控，检验“显式局部趋势＋邻域变化”是否提供额外价值。

模块归因采用严格一致训练；跨架构竞争比较统一数据、评估与预算，同时公开合理训练策略和调参预算。强行给所有架构同一个不合适学习率，也可能产生偏差。

### 13.2 效率

现有更轻、更快的记录不能全归因于结构引导，因为替换同时改变扫描、FFN 和块结构。

当前复杂度脚本使用 THOP 并从已有评估文件读取推理时间：

- 非零 FLOPs 不保证自定义 selective-scan 已完整计数。
- batch 评估的每图时间不等于 batch=1 延迟。
- 1000/ms 不自动是含预处理与 NMS 的端到端 FPS。

建议报告 Params、计算量计数范围、batch=1 延迟、吞吐量、精度、硬件、输入、预热和重复次数，并区分核心模块与完整系统成本。

### 13.3 定性图

优先检测图：同输入下的真值、Original、Matched Base 和最终模型。

样例覆盖小目标、弱响应、近岸背景、孤立强响应、改善与退化。固定并注明显示阈值、NMS 与匹配规则。

机制图另行展示 I、总输入缩放和结构引起的 Delta 变化；不用各自独立拉伸的色图强弱冒充真实数值比较。

当前 Recall 来自各模型最优 F1 工作点，阈值可能不同。若强调召回优势，补 PR 曲线或固定 Precision／误警约束下的 Recall 更合适。

## 14. 种子、统计与测试集使用

现有不同划分＋同种子配对是可接受的设计，无需作废，但方差同时含划分和优化随机性。

短期优先在已有配对条件下补关键控制；后续可对最终少数模型固定划分、增加训练种子。不要在混杂尚未消除时单纯堆种子数量。

如使用 bootstrap，明确抽样单位和估计对象：图像或场景抽样不能替代训练种子不确定性；同源切片不应当作完全独立样本。三种子推断能力有限，不能靠像素数量制造显著性。

SSDD 测试结果已参与研究讨论，不能再称其对开发过程完全未见。后续应冻结比较计划，在验证集选择配置，并以第二数据集的独立测试增强确认性，避免围绕测试结果反复试到正结果。

## 15. 控制实验量的分阶段方案

### 阶段 0：证据审计，不训练

交付：

1. 冻结稿件与方法版本。
2. 每个开关的真实数学和代码语义。
3. 15 个 run 的可复用性表。
4. 72.261% 主结果的来源链。
5. 主指标、选模与评估规则。

出口条件：知道在比较什么，知道哪些结果能复用；若无法建立运行对应关系，明确缺失项，不先扩展大矩阵。

### 阶段 1：核心三个新增配置

优先 Matched Base、固定局部修正背景下的 Input-conditioned、Delta-conditioned。

若两端现有配置完全可复用且无需额外常数缩放控制，三个配置 × 三配对种子 = 9 次新增训练。

这个数量是条件估算，不是保证。若中性定义需要额外控制、实际版本不一致或训练协议改变，应重新计算 run 数。

出口条件：能回答同结构新增机制是否有贡献，以及两条路径各自和条件贡献如何。

### 阶段 2：按证据选择机制补强

- 若主要支持局部修正：拆残差／能量，增加普通滤波对照。
- 若主要支持结构条件化：普通内容门控、全局／常数／打乱引导与实际控制量分析。
- 若均无清晰贡献：先调整假设或方法，不自动扩展更多数据集。

出口条件：能用直接证据而非想象解释最关键的设计选择。

### 阶段 3：第二数据集与充分训练确认

仅带 Original、Matched、最终配置和关键简化对照。

出口条件：确认主要结论不局限于 SSDD 的某一个弱训练或偶然设置。

### 阶段 4：竞争性比较、效率和论文整理

补少量代表性同协议模型，完成效率、预测图、来源和补充材料。

以上阶段不得因写入报告而自动启动。获准执行时先按项目规则盘点已关联服务器、低影响检查身份与资源，使用独立任务目录；不抢占已有任务，不静默回退本机，不启动本机 4050 服务。

## 17. Claim 的安全改写

| 过强或尚未成立的表达 | 当前证据更匹配的表达 |
|---|---|
| 稳定提升检测性能 | 在三个配对实验中取得正向平均差，但方向随条件变化 |
| Full 具有协同增益 | 当前 Full 未超过局部修正组合，协同贡献尚待严格验证 |
| 已证明负交互 | 加入组件后未取得正向平均条件收益，具体原因未确定 |
| I 是可靠性概率 | I 是任务训练的结构条件信号，不是校准概率 |
| Token-wise 优于 Global | 当前 AP50:95 未体现逐位置引导优势 |
| 普遍适用于所有 SAR 任务并提升 | 在多个 SAR 任务上评估适用性与局限 |
| LRC 去除了散斑 | LRC 调整特征域局部响应；去斑解释尚需验证 |
| 模块更快 | 整块替换配置的既有计时更快，机制自身开销需分离测量 |
| 同协议超过文献 SOTA | 文献与本地协议不同，仅作背景，不进行严格排名 |

## 18. Full 若仍不如简化版本，如何决策

### 情况 A：Full 在公平比较下有明确收益

保留 Full，用消融解释各部分必要性，以独立数据条件确认。

### 情况 B：简化配置更好、更快，Full 无其他明确优势

考虑把简化配置作为最终推荐。Full 可作为探索性扩展保留。

如果删除状态条件化，必须重新审视创新点和命名，不能保留完整机制的贡献包装。

### 情况 C：Full 主指标不最高，但某项预先定义能力更好

可围绕低误警召回、困难场景或鲁棒性定位，但需直接证据和性能代价披露。不能在主指标不占优后随意挑次指标制造优势。

### 情况 D：组件作用与组合高度依赖条件

可考虑机制／设计研究，但须输出可迁移知识：何时有效、何时失败、哪些设计选择可推广。

“设计研究”不是对负结果换个名字；只有零散表格而无可检验解释，仍不足以形成完整贡献。
