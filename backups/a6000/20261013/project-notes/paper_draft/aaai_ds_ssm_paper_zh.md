# 面向轻量化 SAR 目标检测的重要性引导去斑状态空间建模

> 2026-07-24 状态：本 Markdown 是早期可读稿。当前完整修订版以 `aaai_ds_ssm_paper_zh.tex` 和编译 PDF 为准。修订版已经重写方法章节，并将 SSDD、SAR-ShipDataset、SAR-AIRcraft 分为三张独立大表，加入参数量和 FLOPs；方法架构图暂缓绘制，请优先阅读 PDF。

## 摘要

合成孔径雷达（SAR）舰船检测面临舰船目标小、分布稀疏、易受斑点噪声和海杂波干扰等挑战。近年来，状态空间模型为视觉长程建模提供了一种高效替代注意力机制的方案，但直接将通用视觉状态空间模块用于 SAR 图像时，噪声主导的 token 可能沿循环状态传播，从而削弱目标定位能力。本文提出一种 Importance-Guided De-Speckle State Space Model（IG-DS-SSM），即面向 SAR 的重要性引导去斑选择性状态空间模块，用于轻量化舰船检测。IG-DS-SSM 首先通过从输入中减去局部残差扰动，构造去斑 token 表征；随后引入能量感知状态抑制机制，以降低不可靠背景状态的传播。为了避免真实舰船响应与噪声一并被抑制，本文进一步设计 Perceptual Feature Importance Module（PFIM），估计 token 级目标重要性，并将其注入记忆保留、状态写入和动态转移步长调制过程。本文将该模块嵌入轻量化 Mamba-YOLO 检测器，并在 SSDD 数据集上进行实验。当前实验显示，PFIM 增强的 DS-SSM 达到 98.704 AP50 和 74.022 AP50:95，同时仅包含 5.96M 参数和 13.21 GFLOPs。与 MaDiNet 等 SAR Mamba 强基线相比，本文方法强调在保持竞争性精度的同时显著降低检测链路复杂度。本文还研究了 DG-DS-SSM 作为解耦门控扩展，用于显式分离 erase、write 和 transition 控制。

## 1. 引言

SAR 图像舰船检测是海上监视、船舶交通管理和应急响应中的基础任务。与光学图像不同，SAR 图像由相干微波成像形成，因此通常包含乘性斑点噪声、强背景杂波以及不同海况下显著的外观变化。舰船目标往往只占少量像素，而波浪、港口和近岸结构产生的强散射可能与目标响应相似。这些特性使检测器很难在抑制背景噪声的同时保留弱舰船结构。

现代目标检测器在自然图像上取得了强性能，其中 YOLO 系列由于计算紧凑，特别适合部署。然而，标准卷积或 Transformer 骨干并未显式考虑 SAR 噪声统计特性。近期视觉状态空间模型成为一种高效长程建模替代方案。通过选择性扫描机制，Mamba 类模型能够以线性复杂度捕获序列依赖，这对密集视觉检测很有吸引力。但它也带来一个 SAR 特有问题：如果某个 token 主要由斑点噪声或海杂波主导，循环状态传播可能将该扰动带入后续 token，污染特征流。

本文从状态空间动态建模角度解决上述问题。我们不只是添加注意力模块或后处理式去噪模块，而是思考如何将 SAR 先验注入状态更新本身。为此，本文提出 Importance-Guided De-Speckle State Space Model（IG-DS-SSM）。核心思想是使状态转移同时感知局部噪声证据和目标重要性。具体而言，局部背景估计器产生残差扰动图，据此构造去偏置输入；能量感知抑制机制控制不可靠区域的历史状态保留；由于高能量响应也可能来自真实舰船，本文进一步引入 PFIM 估计 token 级重要性，并调制三个状态更新组件：记忆保留、当前状态写入和转移步长。

本文将 IG-DS-SSM 嵌入轻量化 Mamba-YOLO 检测器。SSDD 实验显示，PFIM 增强的 DS-SSM 在当前实验归档中取得最优恢复结果，达到 98.704 AP50 和 74.022 AP50:95。该检测器仍保持紧凑规模，在 640 输入分辨率下约为 5.96M 参数和 13.21 GFLOPs。这种精度-效率特性对 SAR 舰船检测很重要，因为实际系统通常要求机载或近实时轻量化处理。

本文贡献如下：

- 提出 DS-SSM，一种面向 SAR 的选择性状态空间模块，通过去斑输入建模和能量感知抑制，降低循环视觉状态中的噪声传播。
- 提出 PFIM，估计感知 token 重要性，并将其注入记忆保留、状态写入和转移步长调制，实现目标感知状态演化。
- 在轻量化 Mamba-YOLO 检测器中实例化该设计，并在 SSDD 上展示其以紧凑计算量获得竞争性检测精度。
- 进一步探索 DG-DS-SSM 解耦门控扩展，分离 erase、write 和 delta 控制，为状态更新分支如何影响 SAR 检测提供可解释证据。

## 2. 相关工作

### 2.1 SAR 舰船检测

SAR 舰船检测既可以使用通用目标检测器，也可以使用 SAR 专用结构。Faster R-CNN 和 Cascade R-CNN 等两阶段检测器具有较强定位能力，但通常计算量较大。RetinaNet、FCOS、YOLO 系列和 YOLOX 等一阶段检测器提供了更好的速度-精度平衡。SAR 专用方法进一步利用散射模式、多尺度上下文或生成式建模处理杂波和目标稀疏性。近期扩散式或一致性检测器提升了表征能力，但可能引入额外推理或训练复杂度。与这些方法不同，本文关注轻量化检测器内部状态更新机制的改进，使 SAR 先验能够在不牺牲部署效率的情况下被编码。

### 2.2 视觉状态空间模型

状态空间模型近年来重新成为高效序列建模方案。Mamba 类选择性状态空间模型使用输入相关参数和硬件友好的扫描操作，以线性复杂度建模长程依赖。视觉变体将该思想扩展到图像 token，并在分类、检测和分割任务中表现出潜力。然而，通用视觉 SSM 模块通常面向自然图像统计特性设计。用于 SAR 图像时，其循环状态可能保留并传播斑点扰动。本文通过 SAR 专用去斑和重要性引导调制修改状态动态。

### 2.3 轻量化 SAR Mamba 检测器

MaDiNet 及相关 SAR Mamba 检测器表明，Mamba 类建模对 SAR 检测有价值。然而，强 SAR 专用检测器可能依赖较大模块或复杂检测框架。本文目标是互补的：构建一条紧凑的 Mamba-YOLO 路线，显式控制斑点传播，并保持低参数量和低 FLOPs，使其更适合计算预算受限的实际场景。

## 3. 方法

### 3.1 总体结构

给定输入 SAR 图像，检测器使用轻量化 Mamba-YOLO 骨干提取多尺度特征。对于特征图 F，首先将其展平为 token 序列：

```tex
x = Flatten(F),  x in R^{N x C},  N = H W.
```

IG-DS-SSM 对 token 序列执行去斑输入建模、重要性估计和选择性状态空间扫描。输出重新变换为二维特征后，送入检测器 neck 和 head。最终论文中的 Figure 1 应展示 Mamba-YOLO 检测器、IG-DS-SSM 插入位置、局部背景估计、PFIM 以及三个重要性引导状态调制路径。

### 3.2 去斑输入建模

SAR 斑点噪声表现为局部波动，容易与弱舰船结构混淆。本文使用深度可分离局部算子估计局部背景表示：

```tex
x_bar = DWConv(x; H, W).
```

局部残差为：

```tex
r = x - x_bar.
```

随后构造去斑输入：

```tex
x_tilde = x - lambda_s r.
```

其中 `lambda_s` 控制残差抑制强度。该操作并不试图去除全部高频信息，而是在进入循环状态传播前，削弱局部扰动成分。

### 3.3 能量感知状态抑制

局部背景能量提供粗粒度可靠性线索。对于 token `t`，计算：

```tex
e_t = ||x_bar_t||_2 / sqrt(C).
```

随后转换为软保留门：

```tex
g_t^E = g_min + (1 - g_min) sigmoid(-alpha e_t).
```

其中 `g_min` 防止状态被完全擦除，`alpha` 控制抑制强度。高能量且不稳定的背景区域会受到更强抑制，从而降低杂波主导历史状态跨 token 保留的风险。

### 3.4 感知特征重要性模块

仅使用能量并不充分，因为舰船目标也可能产生高响应。PFIM 估计 token 级重要性，用于区分目标可能区域和噪声可能区域：

```tex
I_t = PFIM(x_tilde_t, x_bar_t, Std_local(x)_t),  I_t in [0, 1].
```

实际实现中，PFIM 是一个轻量化分支，使用局部二维统计和逐点变换，并通过 sigmoid 输出重要性。中心化重要性记为：

```tex
I_hat_t = I_t - 0.5.
```

### 3.5 重要性引导状态更新

选择性状态空间分支从去斑输入中生成输入相关转移和投影参数。本文使用 PFIM 调制三个更新路径。

记忆保留：

```tex
g_t = g_min + (1 - g_min) sigmoid(-alpha e_t + beta I_hat_t).
```

该门控使目标可能 token 保留更多历史信息，同时抑制噪声可能传播。

状态写入：

```tex
w_t = 1 + rho tanh(I_hat_t)
u_write_t = w_t * u_t.
```

动态转移步长：

```tex
Delta_t = softplus(Delta_t^0 + eta I_t).
```

最终循环更新可概念化写为：

```tex
h_t = g_t * A_bar_t h_{t-1} + B_bar_t u_write_t
y_t = C_t h_t + D x_tilde_t.
```

其中 `D x_tilde_t` 保留当前去斑输入证据，避免所有信息都依赖循环状态传递。

### 3.6 DG-DS-SSM 解耦门控扩展

本文进一步研究 DG-DS-SSM 作为扩展版本，显式分离 erase、write 和 transition 控制。其 retain/erase 分支为：

```tex
r_t = r_min + (1 - r_min) sigmoid(-alpha e_t + beta_e I_hat_t).
```

write 分支为：

```tex
q_t = 1 + s_w tanh(rho_w I_hat_t).
```

delta 分支独立调制转移步长。DG-DS-SSM 对分析很有价值，因为它可以帮助判断旧状态抑制、当前输入写入或转移自适应哪一项对 SAR 检测贡献最大。当前结果中，它具有竞争力，但未超过完整 PFIM 增强 DS-SSM，因此本文将其作为可解释扩展，而非主模型。

## 4. 实验

### 4.1 数据集与指标

本文在 SSDD 上评估，这是 SAR 舰船检测中常用数据集。报告 Precision、Recall、AP50 和 AP50:95。AP50 反映标准 IoU 阈值下的检测可靠性，在 SAR 舰船检测对比中常用；AP50:95 是更严格、对定位更敏感的指标。

### 4.2 实现细节

本文方法实现在 Mamba-YOLO-T 风格检测器中。除非特别说明，实验使用 640 输入分辨率和 300 个训练 epoch。主实验 PFIM 使用 batch size 32 和 SGD 优化器。复杂度在 NVIDIA RTX 3090 上测量，batch size 为 1，精度为 fp32。DDP 只作为训练加速策略，不作为模型贡献。

### 4.3 主结果

当前实验归档中的代表性 SSDD 结果如下：

| 方法 | P | R | AP50 | AP50:95 |
|---|---:|---:|---:|---:|
| Mamba-YOLO-T | 0.9629 | 0.9615 | 0.9849 | 0.7285 |
| DS-SSM ex7 | 0.9610 | 0.9542 | 0.9823 | 0.7352 |
| PFIM ex24 | 0.9570 | 0.9524 | 0.9829 | 0.7357 |
| IG-DS-SSM/PFIM ex27 | 0.9738 | 0.9522 | 0.9870 | 0.7402 |
| DG-DS-SSM ex34 | 0.9700 | 0.9560 | 0.9850 | 0.7350 |

PFIM 增强的 IG-DS-SSM 当前达到最优恢复结果，即 98.704 AP50 和 74.022 AP50:95。

### 4.4 效率分析

在 640 输入分辨率、batch size 1、fp32、RTX 3090 上的复杂度如下：

| 方法 | Params(M) | GFLOPs | Latency(ms) | FPS |
|---|---:|---:|---:|---:|
| Mamba-YOLO-T | 5.9855 | 13.6116 | 26.33 | 37.98 |
| DS-SSM/PFIM | 5.9648 | 13.2079 | 28.75 | 34.78 |
| DG-DS-SSM | 5.9632 | 13.1554 | 29.07 | 34.40 |
| MaDiNet core | 223.2648 | 345.2830 | 27.29 | -- |

需要注意，MaDiNet core 指官方 MambaSAR res4+res5 核心模块，不是完整 MaDiNet 检测器。因此该数字应作为核心模块参考，而不是完整 detector-to-detector 对比。

### 4.5 讨论

结果表明，PFIM 对于让去斑状态空间建模具备目标感知能力很重要。单纯能量抑制可以降低不可靠区域影响，但也可能削弱真实目标响应。PFIM 通过在目标可能 token 附近增强记忆保留和信息写入缓解该问题。DG-DS-SSM 提高了可解释性，并获得有竞争力的 Recall，但其当前最佳结果未在 AP50:95 上超过 PFIM ex27。因此，当前论文应将 IG-DS-SSM/PFIM 作为主贡献，将 DG-DS-SSM 作为有价值扩展。

## 5. 局限性

本稿基于当前恢复的实验归档。最终投稿前仍有两个限制需要处理。第一，PFIM 分支消融最好在统一代码版本下重新运行或验证，以单独确认 retention、write 和 delta 调制的贡献。第二，由于 Detectron2 环境和配置限制，完整 MaDiNet detector 复杂度尚未端到端测量；当前 MaDiNet 复杂度数字指官方 MambaSAR 核心模块。这些限制不改变轻量化 DS-SSM/PFIM 检测器的主结论，但在最终实验部分中需要补齐或清晰说明。

## 6. 结论

本文提出 IG-DS-SSM，一种用于轻量化 SAR 舰船检测的重要性引导去斑状态空间模块。通过构造去斑输入、抑制不可靠状态传播，并使用 PFIM 调制记忆保留、状态写入和转移步长，本文方法将 SAR 噪声感知机制注入选择性状态空间更新过程。SSDD 实验表明，PFIM 增强模型以紧凑计算开销取得较强精度。DG-DS-SSM 解耦扩展进一步为状态控制在 SAR 检测中的作用提供可解释证据。
