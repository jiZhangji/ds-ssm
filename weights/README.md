# Local Weights

This directory is intentionally ignored by Git because checkpoints are large generated artifacts.

Recommended sharing options:

- GitHub Releases for a small curated set of checkpoints.
- External object storage for full experiment archives.
- Git LFS only if the repository owner explicitly wants LFS billing/storage usage.

Keep a short note with each shared checkpoint that records:

- model YAML
- dataset YAML
- training command
- validation/test command
- key metrics
