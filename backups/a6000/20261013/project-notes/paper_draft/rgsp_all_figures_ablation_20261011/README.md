# RGSP 单文件整合工程（2026-10-09）

- **main.tex**：全工程唯一的 `.tex`，包含最新正文、详细实验设置、27次种子结果/配对统计、结构匹配控制、历史九张结果表、原补充内容与统一参考文献。无 `\\input`、`\\include` 或独立 supplement.tex。
- **figures/**：2 张现行主文图、11 张原双栏稿图和一张 10-08 动机历史版本（总计 14 张不同文件），原始 PDF 原样复制；其中老版本方法图仅作为素材保留，正文使用新版。附录展示 9 张历史实验/协议图。
- **figure_sources/**：现行图1/图2的可编辑 SVG，必要时可修改绘图本身。
- **IEEEtran.cls**：编译必需的 IEEE 类文件。

**编译：** 将文件夹整体导入 Overleaf，选择 `main.tex` 作为唯一主文件，Compiler = XeLaTeX；至少编译两遍。正文为 IEEE 双栏，附录自动改为单栏，便于完整展示跨页长表；在正文结论后可直接修改附录并调整其位置。当前版本不代表额外做过训练或验证。

**整理原则：** 以 10-09 最新整合版的研究叙事为正文，补齐 10-09 完整实验版中的全部逐种子与消融表，整合旧历史九表和原独立补充材料；内容重复的简短统计表只保留更详细的版本，不构造实验数值。原始文件中的 `archive/`、构建日志、旧 PDF、校验 JSON、旧脚本、训练源码快照等非 LaTeX 工程依赖资料不再打入精简交付包；已提供的 SSDD/SADD 原始 CSV、种子 JSON 和数值审计 JSON 则完整嵌入 `main.tex` 文件末尾的注释区，方便追溯而无需额外附件。原始四个 ZIP 建议保留作为档案备份。
