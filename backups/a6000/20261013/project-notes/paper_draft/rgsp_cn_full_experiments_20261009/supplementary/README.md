# Supplementary experiment records

`results.csv` contains the five-variant, three-seed SSDD summary. `results_individual.csv` contains all 15 test runs and checkpoint SHA-256 digests. `BASELINE_PROTOCOL.md` records the frozen protocol and limitations. `PAPER_EXPERIMENT_SUMMARY.md` records interpretation and negative findings.

These files are supplied for traceability and are not required to compile `main.tex`.
