# IG-DS-SSM/PFIM 各数据集方法、年份与出处对比表

更新时间：2026-08-30

## 1. 阅读规则

- **本地实测**：来自本项目日志、checkpoint 或 `result.json/eval_test.json`。
- **历史档案**：来自已恢复的旧实验，但训练协议或初始化未完全受控。
- **作者报告**：来自论文或官方结果表，本项目没有按统一协议复现。
- **统一复现表**：某篇后续论文在自己的协议下重跑其他方法；表中同时给出方法原始出处和数值来源。
- 不同划分、输入尺寸、预训练、评价器、HBB/OBB 及 VAL/TEST 的结果不能组成严格排行榜。
- 本项目方法写作“本项目，2026”，表示实验年份，不代表已经正式发表。

## 7. 当前可直接得出的结论

1. 检测任务中，SSDD、OGSOD 和历史 SAR-AIRcraft/SAR-ShipDataset 提供了正向证据；SADD 的受控结果接近持平，AIR-SARShip 和 SRSDD 仍明显落后外部参考。
2. 分类任务中，当前 P3-d16 低于本地 baseline；SAMPLE 缺少相同闭集协议的外部结果。
3. FUSAR-Map 已完成结果与文献不是同一类别定义，暂不能严格比较。
4. 变化检测只在 Farmland 相对本地 baseline 明显提高；其他三个数据集没有支持“通用提升”。
5. 论文主表应优先使用同协议的 baseline 与 ours；作者报告值放入独立的外部参考表。
