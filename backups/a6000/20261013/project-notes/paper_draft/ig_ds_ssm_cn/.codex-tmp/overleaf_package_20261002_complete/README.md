# IG-DS-SSM / PFIM 中文论文工作稿

## 文件

- main.tex：中文论文正文，使用 ctex，可在 Overleaf 以 XeLaTeX 编译。
- figures/：论文引用的 10 张 PDF 图；第 9 张为历史 PFIM 可视化审计，仅作定性示例，不作为机制证据；第 10 张汇总单种子历史检测配对差。
- build_figures.py：从项目结果表和实验记录生成图表的脚本。
- REVIEWER_AUDIT.md：按审稿人视角列出的关键证据缺口与修改优先级。
- main.tex 附录：补充逐 seed SSDD 表、跨任务协议、单种子/历史检测账本、失败运行及实验完成度矩阵；协议不兼容的数据明确分开。

## Overleaf

将本目录中的 main.tex 与 figures 目录一起上传到 Overleaf，将编译器设为 XeLaTeX，然后编译 main.tex。主结果限于 SSDD 三种子受控消融；历史跨任务与跨数据集数字均单独标记，不能与主结果直接比较。当前 PDF 页数以最新编译产物为准；该版本不是投稿定稿。
