# IG-DS-SSM 各任务数据集、代表方法与当前结果

更新时间：2026-08-25

## 1. 证据等级

- **作者报告**：来自论文或官方结果表，未由本项目统一重跑。
- **本地实测**：来自当前项目日志、JSON 或 profiler。
- **历史档案**：来自旧服务器恢复结果，训练协议或初始化未完全受控。
- **待实验**：方案中计划验证，但目前没有本项目结果。

不同数据集的划分、输入尺寸、HBB/OBB、VAL/TEST、预训练和评价器可能不同，下面不能直接组成一个统一排行榜。论文主结论应优先使用同协议的 `Original Mamba/SSM vs. IG-DS-SSM` 对照。

## 2. 当前总体结论

目前真正有本地结果的任务只有**目标检测**。检测中最好的历史结果是 SSDD 上 PFIM ex27 的 `AP50=98.704%`、`AP50:95=74.022%`；最重要的受控结果是 OGSOD-1.0 SAR-only TEST 上，PFIM-T 相比 Mamba-YOLO-T 的 `AP75 +0.760 pp`、`AP50:95 +1.300 pp`。

分割、分类和变化检测部分目前只有公开方法结果与实验方案，尚未完成 IG-DS-SSM 的正式训练，不能把方案中的目标值写成已取得结果。

## 7. 当前应该如何使用这些结果

1. **论文主结果：**优先使用 OGSOD-1.0 的严格受控结果，并补充 SSDD、SAR-ShipDataset、SAR-AIRcraft 的统一重跑。
2. **最好历史性能：**SSDD PFIM ex27，`AP50=98.704%`、`AP50:95=74.022%`，但要标记为历史档案。
3. **最好的受控增益：**OGSOD-1.0，PFIM-T 的 `AP50:95` 比 Mamba-YOLO-T 高 `1.300 pp`，`AP75` 高 `0.760 pp`。
4. **轻量主模型：**IG-DS-SSM/PFIM-T 约 `5.96M Params / 13.2 GFLOPs`；PFIM-S 虽然精度更高，但不应作为轻量主结果。
5. **跨任务扩展：**分割、分类、变化检测目前只能写成计划与公开基线，必须等实际跑出 baseline/ours 配对结果后再宣称通用性。

## 8. 当前最稳妥的论文主线

论文主线建议暂定为：

> IG-DS-SSM: Importance-Guided State Space Modeling for Lightweight SAR Object Detection

核心贡献保持三个：

1. SAR-aware DS-SSM 状态更新，抑制不可靠局部响应；
2. PFIM 对状态保留、写入和步长进行 token 级引导；
3. 在约 6M 参数、13G FLOPs 下取得更好的精度与效率平衡。

分割、分类和变化检测可保留为后续扩展路线，但当前不建议写进主论文的已完成实验结论。
